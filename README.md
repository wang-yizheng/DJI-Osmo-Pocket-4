# DJI-Osmo-Pocket-4
DJI Osmo Pocket 4 是一款专为 Vlog 创作者和旅行记录者设计的口袋云台相机，凭借全新升级的影像系统、更智能的追踪算法和极致的便携性，重新定义了手持拍摄体验。核心影像能力：搭载 1 英寸 CMOS 传感器，配合 f/1.8 大光圈，在低光环境下依然能拍出细节丰富、噪点控制出色的画面；支持 4K/120fps 超清慢动作，能清晰捕捉高速运动瞬间；配备 20mm 等效焦距镜头，视野更广，自拍构图更从容；支持 10-bit D-Log M 色彩模式，保留更多高光和阴影细节，为后期调色提供充足空间。强悍云台与防抖：采用新一代三轴机械云台增稳技术，即使在跑步、骑行等剧烈运动场景下，也能过滤高频震动，保持画面如轨道般平稳；新增智能跟随 6.0，可精准锁定人物、宠物或车辆，即使在复杂环境中也能稳定跟拍；支持手势控制，隔空即可完成拍摄指令。智能与便捷功能：配备 2 英寸旋转触摸屏，横竖拍切换自如，交互直观；支持 Wi-Fi 直播和无线麦克风连接，满足多场景创作需求；内置立体声麦克风，支持降风噪模式，户外收音更清晰；续航长达 2 小时，支持快充，充电 15 分钟即可恢复 80% 电量。套装与配件选择：标准套装（相机主机、保护壳、手绳等基础配件）适合日常记录和轻度创作；全能套装（标准套装 + 无线麦克风 + 迷你三脚架 + 增广镜）适合专业 Vlog 创作者和旅行博主；另有续航手柄、防水壳等专项配件供特定场景选择。选购建议：新手或偶尔拍摄选标准套装即可；计划专业创作或长途旅行，强烈建议选择全能套装，无线麦克风和增广镜能显著提升收音和构图体验；存储卡需单独购买，建议选择 V30/A2 等级以上的 microSD 卡，以确保 4K/120fps 高码率录制的稳定性。
